# 🔐 Common Protocols & Ports

Understanding **protocols and ports** is important when configuring servers, firewalls, cloud infrastructure, and containers.

## 📋 Protocol Reference

| Protocol | Port | Transport | Purpose |
|---|:---:|---|---|
| 🌍 **HTTP** | `80` | TCP | Web traffic |
| 🔒 **HTTPS** | `443` | TCP | Secure web traffic |
| 🖥️ **SSH** | `22` | TCP | Secure remote access |
| 📁 **FTP** | `21` | TCP | File transfer |
| 🔎 **DNS** | `53` | TCP / UDP | Domain name resolution |
| 📧 **SMTP** | `25` | TCP | Email transmission |
| 🌐 **DHCP** | `67 / 68` | UDP | Automatic IP configuration |
| 🗄️ **MySQL** | `3306` | TCP | MySQL database communication |
| 🐘 **PostgreSQL** | `5432` | TCP | PostgreSQL database communication |

---

## 🚀 DevOps Relevance

Ports are commonly used when working with:

- ☁️ **Cloud Security Groups**
- 🔥 **Firewall rules**
- 🖥️ **Remote server access**
- 🌍 **Web application deployment**
- 🗄️ **Database configuration**
- 🛠️ **Network troubleshooting**
- 🐳 **Docker containers**
- 🔄 **CI/CD infrastructure**

> 💡 **DevOps Tip:** Knowing which port a service uses makes troubleshooting and configuring network access much easier.
