### 💻 Commands & Concepts Practiced

| Task | Tool / Concept |
|---|---|
| 🌐 Check network connectivity | `ping` |
| 🛰️ Trace network paths | `traceroute` |
| 🔌 Inspect listening ports | `ss` / `netstat` |
| 🌍 Send HTTP requests | `curl` |
| 🔎 Perform DNS queries | `dig` |
| 🔍 Resolve domain names | `nslookup` |
| ☁️ Explore cloud networking | AWS EC2 |
| 🛡️ Configure network access | Security Groups |
| 📝 Document concepts | Markdown / GitHub |
