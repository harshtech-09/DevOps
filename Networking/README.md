🌐 Networking Fundamentals for DevOps

A hands-on learning repository focused on Networking fundamentals, Linux networking commands, cloud networking, and AWS EC2 Security Groups — essential concepts for building a strong foundation in DevOps and Cloud Engineering.

This repository documents my learning, practical experiments, commands, and notes while exploring how systems communicate and how network traffic is managed and secured.

📌 What I Learned

Throughout this learning journey, I explored:

• OSI & TCP/IP networking models
• Networking protocols and ports
• IP addressing and basic networking concepts
• DNS and domain name resolution
• AWS EC2 networking
• AWS Security Groups
• Linux networking commands
• HTTP/HTTPS communication
• Network troubleshooting fundamentals
• Practical networking scenarios


🛠️ Practical Learning

The focus of this repository is not only theoretical learning.

I practiced:

• Checking connectivity using ping
• Tracing network paths using traceroute
• Inspecting listening ports
• Sending HTTP requests using curl
• Performing DNS queries using dig
• Resolving domains using nslookup
• Exploring EC2 networking
• Understanding Security Group rules
• Documenting networking concepts and commands
